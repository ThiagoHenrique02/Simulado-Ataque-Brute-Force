# 🔐 Simulação de Brute Force com Medusa

Projeto educacional desenvolvido para estudar o funcionamento de ataques de **Brute Force** utilizando a ferramenta **Medusa**, em um ambiente de laboratório controlado.

O objetivo é compreender como tentativas automatizadas de autenticação podem ser realizadas e, principalmente, como esse tipo de atividade pode ser identificado e mitigado em um ambiente de segurança.

## 🎯 Objetivos

* Compreender o conceito de ataques de Brute Force;
* Conhecer a ferramenta Medusa;
* Estudar processos de autenticação em serviços de rede;
* Praticar conceitos de segurança ofensiva;
* Analisar possíveis mecanismos de detecção e proteção contra tentativas automatizadas de login;
* Desenvolver conhecimentos práticos em Cibersegurança.

## 🧪 Ambiente de Laboratório

O projeto foi desenvolvido em um **ambiente controlado**, utilizando máquinas virtuais para realizar os testes de forma segura e isolada.

A simulação é realizada somente contra sistemas próprios ou ambientes preparados especificamente para testes de segurança.

## 🧰 Tecnologias e Ferramentas

* Kali Linux
* Medusa
* Linux
* Máquina virtual
* Ambiente de laboratório

## 📚 Conceitos abordados

* Brute Force
* Autenticação
* Senhas e credenciais
* Serviços de rede
* Segurança ofensiva
* Detecção de ataques
* Mitigação de ataques de força bruta

## ⚠️ Aviso de Segurança

Este projeto possui **finalidade exclusivamente educacional**.

Os testes devem ser realizados somente em máquinas, serviços e ambientes para os quais você tenha **autorização explícita**. Não utilize a técnica contra sistemas ou contas de terceiros.

O objetivo deste projeto é compreender o funcionamento de ataques de força bruta e estudar formas de **identificação, prevenção e defesa** contra esse tipo de ameaça.

## 📌 Contexto

Este projeto faz parte dos meus estudos práticos de **Cibersegurança e Linux**, utilizando o Kali Linux e ferramentas de segurança para compreender conceitos de segurança ofensiva e defensiva.
